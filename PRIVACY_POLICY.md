# Política de Privacidad - PedidAPP

**Última actualización:** 1 de abril de 2026

## Introducción

PedidAPP ("la Aplicación") es una aplicación móvil diseñada para la organización de compras del hogar y control de stock. Esta Política de Privacidad describe cómo se recopila, utiliza y protege tu información cuando utilizas nuestra Aplicación.

## Información que Recopilamos

### Datos Almacenados Localmente
PedidAPP almacena todos los datos **exclusivamente en tu dispositivo**. No se envía información a servidores externos. Los datos almacenados incluyen:

- **Productos:** Nombres, categorías, cantidades de stock, precios estimados y notas que ingreses.
- **Listas de compras:** Listas que crees, items añadidos y su estado de compra.
- **Presupuesto:** Montos de presupuesto mensual y gastos registrados.
- **Registros de consumo:** Historial de uso de productos para predicciones de stock.
- **Preferencias:** Configuraciones como tema (claro/oscuro) y preferencias de notificaciones.

### Datos que NO Recopilamos
- **No** recopilamos datos personales identificables (nombre, email, teléfono).
- **No** recopilamos datos de ubicación.
- **No** utilizamos servicios de análisis o seguimiento (analytics/tracking).
- **No** mostramos publicidad.
- **No** compartimos datos con terceros.

## Permisos del Dispositivo

La Aplicación puede solicitar los siguientes permisos:

| Permiso | Propósito |
|---------|-----------|
| **Notificaciones** | Alertas de stock bajo y avisos de presupuesto |

Estos permisos son opcionales y la Aplicación funciona sin ellos, aunque con funcionalidad reducida.

## Almacenamiento de Datos

- Todos los datos se almacenan en una base de datos SQLite local en tu dispositivo.
- Los datos persisten hasta que los elimines manualmente o desinstales la Aplicación.
- **Desinstalar la Aplicación elimina todos los datos permanentemente.**

## Compartir Información

La función "Compartir lista" permite enviar el contenido de una lista de compras a través de aplicaciones de mensajería (WhatsApp, SMS, etc.). Esta acción es iniciada exclusivamente por ti y utiliza las funciones nativas de compartir de tu dispositivo.

## Seguridad

Dado que todos los datos se almacenan localmente en tu dispositivo, la seguridad de tus datos depende de las medidas de seguridad de tu propio dispositivo (bloqueo de pantalla, encriptación del dispositivo, etc.).
